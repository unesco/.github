# UNESCO Code Repository

*"Building peace in the minds of men and women"*

[![UNESCO](https://img.shields.io/badge/UNESCO-Data%20%26%20AI-0077B6?logo=united-nations&logoColor=white)](https://www.unesco.org)

Welcome to UNESCO's official open-source hub — technology for education, science, culture, and sustainable development.

## What We Build

- **AI & Machine Learning**: Python models, multilingual NLP, text-to-speech, video analysis
- **Data Platforms**: Analytics pipelines, data classification, privacy tools
- **Educational Technology**: Learning tools, quiz generation, content transformation
- **Digital Heritage**: 3D modeling, heritage site visualization, cultural preservation
- **Sustainability Tools**: SDG classification, monitoring, reporting

## AI & Data Tools

| Repository | Description |
|---|---|
| [pdf-to-podcast](https://github.com/unesco/pdf-to-podcast) | Transform scientific PDFs into podcast-style audio conversations |
| [heritage-3d-generator](https://github.com/unesco/heritage-3d-generator) | Generate 3D models of UNESCO World Heritage Sites |
| [pii-detector](https://github.com/unesco/pii-detector) | Detect and redact personally identifiable information |
| [sdg-classifier](https://github.com/unesco/sdg-classifier) | Classify text into Sustainable Development Goals |
| [video-to-quiz](https://github.com/unesco/video-to-quiz) | Convert educational videos into structured quizzes |

## Our Principles

All projects follow the **[UNESCO Recommendation on the Ethics of AI](https://www.unesco.org/en/artificial-intelligence/recommendation-ethics)** and prioritize:
- Human rights and dignity
- Transparency and explainability
- Privacy and data protection
- Fairness and non-discrimination
- Environmental sustainability

## Getting Started

1. **Browse by Technology**: Filter repositories by language (Python, JavaScript, PHP, etc.)
2. **Explore by Mission Area**: Education, culture, science, communication, SDGs
3. **Check Documentation**: Each project includes setup guides and usage instructions
4. **Follow Installation Guides**: Most projects use Poetry for dependency management
