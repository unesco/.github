## Our Principles

All projects follow the **[UNESCO Recommendation on the Ethics of AI](https://www.unesco.org/en/artificial-intelligence/recommendation-ethics)** and prioritize:

- Human rights and dignity
- Transparency and explainability
- Privacy and data protection
- Fairness and non-discrimination
- Environmental sustainability

## Contributing

We welcome contributions from developers worldwide. Please review each project's README and contributing guidelines before submitting pull requests. All contributions must be compatible with UNESCO's ethical standards.
